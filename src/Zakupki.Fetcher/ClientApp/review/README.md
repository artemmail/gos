# Проверка интерфейса

## Сборка и браузерная проверка

```powershell
npm run build:production
npm run review:ui
```

Проверка запускает локальный HTTP-сервер на `127.0.0.1:4338` и Chrome без окна.
Ожидается установленный Chrome по стандартному пути Windows. DevTools использует порт 9468.
Сервер и браузер завершаются после проверки. Скриншоты и результаты сохраняются в `review/artifacts/`.

API и SignalR в проверке заменены изолированными тестовыми ответами. Скрипт не обращается к рабочей базе,
не использует настоящие аккаунты и не изменяет данные сервиса. В production-сборке тестовых данных нет.
Внешняя авторизация у провайдеров, работа настоящего сервера анализа и содержимое скачанных отчётов
требуют отдельной интеграционной проверки в окружении приложения.

## Основные сценарии

- Вход с возвратом на запрошенную страницу, отображение ошибки, сохранение пользовательских настроек.
- Поиск по ключевым словам, точному номеру и сохранённому направлению; сортировка и пагинация на сервере.
- Полный сброс фильтров, восстановление параметров после обновления страницы, компактный вид.
- Добавление и удаление избранного; результаты в избранном ограничены сохранёнными закупками.
- Просмотр анализа, карточки закупки и документов.
- Сохранение профиля, добавление направления, предупреждение о несохранённых изменениях.
- Ошибки поиска и профиля, повторная загрузка и пустые результаты.
- Навигация с клавиатуры на мобильном экране, восстановление фокуса, отсутствие горизонтального переполнения.
- Кириллица в имени пользователя и восстановление после повреждения локального кеша.

## Структура UI

Цвета, типографика, общие элементы и адаптивные правила — `src/styles.css`.
Тема Angular Material — `src/theme.scss`. Шрифты поставляются вместе с приложением.
Навигация рабочего пространства — `app.component.*`.
Стили результатов поиска разделены на панель поиска и `notices/tender-card.css`.
Иллюстрация на публичной странице создана средствами HTML/CSS, обозначена как пример
и вынесена в `presentation-page/product-preview.css`.

Основной путь: **профиль компании → поиск → избранное → анализ → документы и решение**.
Старые адреса `/notices` и `/tenders-start` перенаправляются на актуальные страницы.
Маршрут Фабрикант сохранён, но исключён из основной навигации: в текущем backend проекта
не найден обработчик существующего запроса `/notices-fab?source=3`.

Сборка находится в `dist/zakupki-fetcher-client/`. Публикация в серверный `wwwroot` не выполнялась.
